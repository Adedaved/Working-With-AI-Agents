# Agent Communication Protocol: ACP

[Chapter overview](README.md) | [Course home](../README.md)

## In plain English

ACP describes a framework-independent approach to communication between agents. IBM keeps both an explainer and an interoperability tutorial in its navigation. Its explainer now explicitly notes that ACP has merged with A2A under the Linux Foundation and that active ACP development is winding down. Study ACP to understand interoperability concepts and older examples, while checking the official migration path before starting a new implementation. Keeping its place here preserves IBM's topic structure without presenting an older tutorial as the current default.

## Try it: original exercise

1. Read the status note at the top of IBM's ACP explainer.
2. Identify the sender, receiving agent, request and returned result in the interoperability guide.
3. Write a framework-neutral handoff for a ticket-summary task.
4. For a new implementation, evaluate current A2A documentation and migration requirements.

## Check your understanding

Should this tutorial remove ACP simply because its status changed?

**Answer checkpoint:** No. Retain IBM's topic, explain its current status and direct implementation choices accordingly.

## Common mistake

Do not assume packages or examples for ACP and A2A are interchangeable.
