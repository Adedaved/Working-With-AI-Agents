[Course home](../README.md)

## What you will learn

Distinguish agent-to-tool connections from agent-to-agent communication.

## Start here

Protocols standardize communication at a boundary between systems. MCP primarily connects an AI application to tools and resources. A2A supports communication between agents. ACP remains in IBM's navigation as an earlier interoperability approach, with an explicit migration status note. Protocol compatibility is separate from authorization: systems still need identity, validated inputs and permitted actions.
