## What you will learn

Recognize the frameworks in IBM's navigation and match their design patterns to a task.

## Start here

Frameworks provide implementation patterns and reusable components. Compare them by the workflow you need: tool access, state, branching, collaboration, human review and operational visibility. The lessons follow IBM's framework list without claiming one universal winner. Implementation labs are linked rather than copied, because package APIs and platform prerequisites change. Check the selected guide and dependency versions before running a lab.
