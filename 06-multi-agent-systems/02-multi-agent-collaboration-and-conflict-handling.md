# Multi-agent collaboration and conflict handling

[Chapter overview](README.md) | [Course home](../README.md)

## In plain English

Agents collaborate through shared information, assigned responsibilities and coordinated actions. The key operating questions are who owns each task, which source is authoritative and how disagreements are resolved. Coordination can be centralized or distributed. For a small project, simple message contracts and one artifact owner are often enough. More elaborate collaboration should earn its complexity through measured improvements.

## Try it: original exercise

1. Give two reviewers different source subsets and ask for evidence-linked findings.
2. Merge findings using source identifiers rather than prose alone.
3. Resolve conflicting claims by inspecting the underlying records.
4. Assign one owner to update the final report and record unresolved issues.

## Check your understanding

What should happen if conflicting evidence cannot be resolved?

**Answer checkpoint:** Report the conflict and uncertainty instead of presenting an artificial consensus.

## Common mistake

Shared memory without source and version information can spread errors through the team.
