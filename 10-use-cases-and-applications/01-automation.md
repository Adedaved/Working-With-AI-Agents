## In plain English

Agentic automation combines interpretation with actions in a business workflow. Use deterministic code for exact checks and an agent where variable context calls for interpretation. The best starting tasks have observable inputs, bounded actions and a result that can be reviewed. Build exception handling into the workflow so uncertain records become a review queue rather than invented answers.

## Try it: original exercise

1. Choose a recurring file-review task with explicit rules.
2. Separate exact validation from judgment-dependent classification.
3. Produce a draft report with an exception queue and source references.
4. Measure completeness and review effort against the manual process.

## Check your understanding

When is a conventional script preferable?

**Answer checkpoint:** When rules and inputs are stable and exact automation already meets the requirements.

## Common mistake

Using an LLM for every step can add cost and variability without adding value.
