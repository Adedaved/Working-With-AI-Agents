## Start here

Architecture determines how the decision engine, state, tools and coordination fit together. Choose a single-agent design when it can meet the goal; add specialists when the work justifies their coordination cost. Gateways regulate access, while control planes manage the wider fleet. ReAct and ReWOO are patterns for organizing decisions and evidence collection. None of these choices removes the need for verification.
