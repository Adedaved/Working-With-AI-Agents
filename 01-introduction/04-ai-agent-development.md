# AI agent development

[Chapter overview](README.md) | [Course home](../README.md)

## In plain English

Development means designing the goal, model interaction, context, tools, execution rules and evaluation together. You can build these pieces yourself or use a framework that supplies common plumbing. Start with a problem statement and a small successful workflow before adding features. Tool permissions, failure handling and evaluation belong in the design from the beginning. An agent is a software system around a model, so changing a prompt is only one part of development.

## Try it: original exercise

1. Write a one-paragraph specification for a read-only incident-summary agent.
2. List its sources, tools, expected output and forbidden actions.
3. Define three representative examples and their expected results.
4. Implement or configure the smallest workflow, then inspect each result.

## Check your understanding

What should come before selecting a framework?

**Answer checkpoint:** A concrete use case, success criteria, data requirements and action boundaries.

## Common mistake

A framework reduces implementation work; it does not supply missing domain standards.
