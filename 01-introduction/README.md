## What you will learn

Understand what agents do, how they differ from assistants, and how to define a useful first task.

## Start here

An agent works toward a goal by observing inputs, selecting actions and checking results. Modern LLM agents combine a reasoning model with context, a reachable workspace and tools. A good first task has a concrete output and a reviewer who knows what counts as correct. Define scope and success before starting, then review the output and the actions taken. Use feedback to improve the instructions, context or access. The broader AI taxonomy also includes agents that do not use LLMs.
