# Agentic AI versus generative AI

[Chapter overview](README.md) | [Course home](../README.md)

## In plain English

Generative AI creates or transforms content such as text, code or images. Agentic AI organizes actions toward a goal, often using generated content along the way. They can be parts of the same system. Drafting a release note is a generation task; checking commits, finding relevant changes, drafting a release note and saving it for review is a workflow. Generation explains what the model produces, while agency describes how the surrounding system behaves.

## Try it: original exercise

1. Choose a deliverable: a release summary.
2. Identify the generation step: write the prose.
3. Identify the action steps: inspect commits, collect evidence and save the file.
4. Define the human review required before publication.

## Check your understanding

Does generating a long document automatically make a task agentic?

**Answer checkpoint:** No. Length is not agency; tool use, goal-directed execution and progress across steps matter.

## Common mistake

An agent does not have to use several models or several agents.
