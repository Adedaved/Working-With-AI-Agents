# Evolution of AI agents

[Chapter overview](README.md) | [Course home](../README.md)

## In plain English

Agents have roots in rule-based systems, robotics and research on systems that perceive and act. LLMs made language-driven interaction and flexible task decomposition more accessible, but did not invent agency. Modern deployments combine models with software, state, external tools and human oversight. The useful lesson from this history is that an LLM is one possible decision engine; many narrow automated tasks can be handled more simply.

## Try it: original exercise

1. Describe a threshold alert that follows a fixed rule.
2. Describe a system that remembers previous alerts to suppress duplicates.
3. Describe an LLM workflow that interprets a ticket and chooses an appropriate runbook.
4. Compare which parts need rules, stored state or flexible interpretation.

## Check your understanding

Must every agent contain an LLM?

**Answer checkpoint:** No. IBM's broader taxonomy includes rule-based and other non-LLM agents.

## Common mistake

Avoid equating all historical agents with today's conversational LLM agents.
