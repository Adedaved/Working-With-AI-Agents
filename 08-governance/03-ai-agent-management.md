# AI agent management

[Chapter overview](README.md) | [Course home](../README.md)

## In plain English

Management gives agents owners, approved purposes and consistent operating rules. It spans coordination, access, monitoring, changes and incident response. Document who can create or release an agent, who reviews its work and who responds to failures. Management becomes especially important when multiple teams adopt agents independently. A small register and a clear release process are useful starting points.

## Try it: original exercise

1. Create an agent register with purpose, owner, sources and tools.
2. Record approved permissions and escalation contacts.
3. Require evaluation evidence for significant configuration changes.
4. Review active agents periodically for performance, redundancy and obsolete access.

## Check your understanding

Who should respond when an agent repeatedly uses the wrong source?

**Answer checkpoint:** The named workflow owner, supported by the appropriate technical or domain reviewer.

## Common mistake

Ownership should refer to an accountable person or team, not only the agent's display name.
