# 08. Governance

[Course home](../README.md)

## What you will learn

Define ownership, evaluation, security, supervision and operational accountability.

## Start here

Governance defines who owns agents, what they may do and how acceptable performance is demonstrated. Evaluation examines outputs and trajectories; observability helps diagnose behavior; security constrains access and execution; human review resolves consequential decisions. Keep these responsibilities attached to the actual workflow rather than treating them as optional paperwork.
