# 02. Components

[Course home](../README.md)

## What you will learn

Understand the capabilities that turn a model into a system that can observe, decide and act.

## Start here

The components work together: perception supplies observations; memory supplies relevant state; reasoning and planning choose what to do; tools perform actions; communication coordinates handoffs; and feedback supports improvement. These functions can be implemented differently in different systems. Separate the model's learned capabilities from context and persistent stores. Understand what each component contributes before choosing a framework.
